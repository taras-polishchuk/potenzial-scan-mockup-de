## What is this

Visual prototype of the Potenzial-Scan Lite wizard — a 5-minute AI assessment that helps German Mittelstand companies find which business process to automate first.

- INTRO screen (Decide/Learn surface) with Liquid Glass aesthetic
- 5-step wizard (S1–S5) — company context → process description → contact (phone banner) → AI analysis → final gate (email + DSGVO consent)
- Pre-Intelligence Dossier side panel — research the prospect's company BEFORE they type anything
- Result dashboard (S6) — reactive, derives recommendations from form inputs
- Saved state (S7) — localStorage persistence

---

## Privacy

- NO real data sent to Perplexity (mock data, 8 production hooks documented)
- localStorage only (no server-side persistence)
- DSGVO Art. 6(1)(a) — explicit consent before any data collection
